Accès Admin — chantier 6

En tant que créateur de Bloomday, qu'est-ce que tu veux pouvoir faire ?

A

Voir tous les utilisateurs

Liste de tous les comptes créés : email, date d'inscription, plan (gratuit / premium), statut actif. Pouvoir chercher un utilisateur précis.

B

Statistiques d'usage

Nombre d'inscrits, actifs par semaine/mois, messages générés, taux de conversion gratuit → premium, revenus estimés.

C

Voir les données d'un utilisateur

Pour un compte précis : ses contacts, groupes, événements, historique. Utile pour le support client ("je n'arrive pas à...") et pour débugger.

D

Envoyer une notification à tous

Broadcaster un message à tous les utilisateurs (nouvelle fonctionnalité, maintenance, promo). Bannière ou message dans l'app.

🔒 Sécurité
L'accès admin sera protégé par ton email Supabase uniquement — aucun autre utilisateur ne peut y accéder.
