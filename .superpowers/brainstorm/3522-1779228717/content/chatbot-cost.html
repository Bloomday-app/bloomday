Chatbot IA — modèle de coût

Deux approches selon ton niveau d'implication souhaité

A

🔑 Claude (Anthropic) — clé API unique dans Netlify

Setup : 1 clé API → 1 variable dans Netlify → jamais y retoucher

Coût : ~2-10€/mois selon usage. Tu mets un plafond mensuel dans le dashboard Anthropic.

Qualité : Meilleure IA disponible. Répond vraiment bien.

Ton niveau d'implication : Zéro après le setup. Ça tourne tout seul.

B

🆓 Gemini Flash (Google) — tier gratuit

Setup : Clé API Google gratuite → Netlify → jamais y retoucher

Coût : 0€ jusqu'à 1 million de messages/mois (tier gratuit Google)

Qualité : Très bonne. Légèrement en dessous de Claude mais largement suffisant pour un chatbot FAQ + rédaction de messages.

Ton niveau d'implication : Zéro après le setup. Complètement gratuit.

💡 Dans les deux cas
Tu configures ça une seule fois au démarrage.
Après, tu n'y touches plus. L'app gère tout : quotas, limites par utilisateur, messages d'erreur.
Aucune facture surprise grâce aux plafonds configurés côté Google/Anthropic.
