Chatbot IA — qui peut l'utiliser ?

Chaque message coûte ~0,001€ en API Claude — il faut décider qui y a accès

A

Tout le monde (visiteurs + connectés)

Sur la landing page et dans l'app. Les visiteurs voient le chatbot, posent des questions, ça les aide à se convertir. Risque : abus possible sans limite.

→ Ajouter une limite : 3 messages max pour visiteurs non connectés, illimité pour les abonnés

B

Connectés uniquement (in-app)

Le chatbot n'apparaît que dans l'app après connexion. Coût maîtrisé, pas de risque d'abus. Sur la landing page : juste un bouton "Essayez Bloomday → connexion requise".

C

Landing page uniquement (avant connexion)

Sert uniquement à convertir les visiteurs — répond aux questions produit, pousse vers l'inscription. Désactivé une fois connecté (l'app a déjà assez de fonctionnalités).

D

Partout, avec quota selon le plan (recommandé)

Disponible sur landing (3 msg gratuits) et dans l'app. Gratuit : 10 msg/mois. Premium : illimité. C'est aussi un argument de vente pour l'abonnement payant.
